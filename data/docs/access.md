# 访问与权限

> 自编合成教学资料，虚构 Atlas 平台；不是现实产品说明。

## [access.token] 访问令牌

Atlas 为虚构的研发资料平台，本库所有规则仅用于练习。调用 API 时在 Authorization 请求头发送 Bearer 访问令牌。令牌有效期为 2 小时；过期返回 AUTH_401_EXPIRED。客户端应重新申请令牌，然后最多重试一次。不要在日志中记录完整令牌。

## [access.role] 成员角色

访客只能读取公开资料，编辑者可以上传和修改自己项目中的文档，管理员可以授予角色。私有项目必须先通过项目成员权限检查，再执行检索；重排序不能代替访问控制。

## [access.rotate] 密钥轮换

项目 API 密钥每 30 天轮换一次，新旧密钥有 24 小时重叠期。重叠期结束后旧密钥失效。轮换项目密钥不会延长已经签发的访问令牌有效期。
