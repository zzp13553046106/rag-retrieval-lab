# 核心函数练习说明

## 文件怎么用

- `core_functions_reference.py`：现有实现的参考摘录。保留原函数体语义，省去模型下载和初始化代码以及长篇注释；模型接口仍借用原 `Engine` 的初始化。
- `core_functions_practice.py`：对应的练习骨架，函数体由你填写。`NotImplementedError` 表示练习尚未完成，不是主程序发生故障。
- `rag.py`：项目实际执行的代码。本轮没有改动它，也没有把练习骨架接入项目。

两个学习文件导入时均不会创建引擎或加载模型。真正创建 `EngineCore` 实例仍会使用原有模型环境；先完成纯函数练习，无需加载权重。

这是依赖原项目的分函数练习，不是一套独立部署实现。`EngineCore` 沿用原初始化时，使用的是原项目的文档加载与 BM25；练习中的 `load_chunks` 和 `BM25` 需要分别验证，完成后再决定是否接入原工程。

## 先写这四块

| 顺序 | 入口 | 输入 | 输出 | 重点 |
|---|---|---|---|---|
| 1 | `rank(scores, k)` | 各片段分数、保留数量 | 排好序的片段下标 | 分数降序、同分稳定、下标与分数区别 |
| 2 | `rrf(rankings, constant)` | 两路或多路排名 | 融合后的下标排名 | 名次从1开始、跨路贡献累加、去重；截取候选在调用方完成 |
| 3 | `metrics(ids, relevant, k)` | 检索排名、标准证据 | Recall、MRR、nDCG | 多证据覆盖、第一条正确证据的位置、无答案题 |
| 4 | `EngineCore.search(query)` | 原始问题、引擎已保存的数据与模型 | 四份排名、重排分数、耗时 | 两路各8 → 融合留8 → 重排8；这里不生成答案 |

可以先按原有等权 RRF 完成，不需要一开始加入动态权重或替换融合算法。

## 另外这些要能读懂和定位

| 入口 | 必须解释清楚的事情 |
|---|---|
| `load_chunks()` | 如何读文档、切块、保留来源；400是字符目标，不是严格硬上限 |
| `BM25.__init__()` / `scores()` | 词频、逆文档频率、长度归一化如何参与打分 |
| `EngineCore.encode()` | 如何调用向量模型、截断、归一化；问题向量与文档向量如何对应 |
| `EngineCore.rerank()` | 问题与每个候选分别配对，独立打分后排序 |
| `EngineCore.generate()` | 取前三段、门控、拼接资料、调用回答模型、诊断引用 |

`tokens()` 在参考文件中保留，练习文件直接引用原实现；本轮不要求自己写分词器。神经网络内部结构、模型训练与微调也不属于这些函数的实现范围。

## 三个明确的验收例子

以下是教学输入，不是新的项目评测结果。

### 排序

```python
rank([0.2, 0.9, 0.4], 2) == [1, 2]
rank([0.5, 0.5], 2) == [0, 1]
rank([], 3) == []
```

负数 `k` 应抛出 `ValueError`；`k=0` 返回空列表。

### RRF融合

```python
rrf([[0, 1, 2], [3, 1, 4]], 60) == [1, 0, 3, 2, 4]
```

片段1在两路都是第二名，总贡献为 `1/62 + 1/62`。片段0只在一路第一名，贡献为 `1/61`。这两个分数用于排序，不表示正确概率。

### 指标

```python
metrics(['x', 'a', 'b'], ['a', 'b'], 3)
# recall = 1.0
# mrr = 0.5
# ndcg 约为 0.6934
```
