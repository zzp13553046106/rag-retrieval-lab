# 第一课：看懂一个问题怎样变成四份排名

本课只读 `rag.py` 的 `Engine.search()`。它负责检索与排序，不生成最终答案。

## 输入与对象

`query` 是用户输入的字符串。`self` 是当前Engine对象，其中保存资料、文档向量、BM25与重排模型。

`self.chunks[i]` 保存第i个片段的来源与正文，`self.texts[i]` 保存用于模型计算的文本，`self.vectors[i]` 是该文本的向量。三个数组里的同一个i对应同一片段。

数组下标如0、5、12用于取数据；证据ID如 `search.dense` 用于引用和评测，二者不是同一个东西。

## 逐步看四个变量

| 变量 | 如何产生 | 装的是什么 |
|---|---|---|
| b | 对所有片段算BM25，取前8 | 关键词排名的片段下标 |
| d | 对问题编码，与文档向量点积，取前8 | 语义排名的片段下标 |
| h | RRF融合b和d，再截前8 | 最终进入重排的候选下标 |
| r | Cross-Encoder对问题与h中的片段成对打分 | 重排后的片段下标 |

`bs`、`ds` 是每个片段的分数；`b`、`d` 是根据分数排列的下标，注意不要混淆。

## 看懂一个矩阵计算

```python
q = self.encode([指令前缀 + query])[0]
ds = self.vectors @ q
```

假设共有N个片段，向量维度为D：

- `encode([...])` 得到 `[1, D]`；`[0]`取出唯一那行，形状为 `[D]`。
- `self.vectors` 形状为 `[N, D]`。
- 点积结果 `ds` 形状为 `[N]`，每个数对应一个片段。

向量已做L2归一化，所以点积等于余弦相似度。这里没有逐字匹配，也没有执行模型训练。

## 手算一次RRF

假设演示排名为 `b=[0,1,2]`、`d=[3,1,4]`，融合常数60。片段1在两路都排第2，贡献为 `1/62+1/62`；片段0只在一路排第1，贡献为 `1/61`。片段1的总分更高。

注意：这里只是规则下的排名分数，不能解释成“片段1有某个百分比概率是正确的”。
